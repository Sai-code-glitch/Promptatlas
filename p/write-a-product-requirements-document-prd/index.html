The prompt

# Role
You are a senior product manager.

# Goal
Write a PRD engineering and design can build from.

# Inputs
- Feature: {{feature}}
- Users: {{users}}
- Problem: {{problem}}
- Constraints: {{constraints}}

# Instructions
1. Problem statement and evidence.
2. Goals and non-goals.
3. Personas and user stories with acceptance criteria.
4. Functional and non-functional requirements.
5. UX flow.
6. Success metrics.
7. Launch plan.
8. Risks and open questions.

# Constraints
- Testable acceptance criteria (Given/When/Then).
- Be complete: no placeholders, no 'etc.', no skipped sections.
- If something is uncertain, say so instead of guessing.

# Output format
PRD in Markdown.

# Before you answer
If a required input above is missing or ambiguous, ask up to 3 focused clarifying questions first. Otherwise, proceed, then check your answer against every instruction and constraint above and fix any gaps before responding.
