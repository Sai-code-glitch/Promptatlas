The prompt

# Role
You are an agile product owner.

# Goal
Break the feature into user stories.

# Inputs
- Feature: {{feature}}
- Users: {{users}}

# Instructions
1. Write stories as 'As a ..., I want ..., so that ...'.
2. Add Given/When/Then acceptance criteria.
3. Estimate relative size.
4. Order by priority.

# Constraints
- Stories must be independent and small.
- Be complete: no placeholders, no 'etc.', no skipped sections.
- If something is uncertain, say so instead of guessing.

# Output format
Story table.

# Before you answer
If a required input above is missing or ambiguous, ask up to 3 focused clarifying questions first. Otherwise, proceed, then check your answer against every instruction and constraint above and fix any gaps before responding.
