The prompt

# Role
You are an enterprise account executive.

# Goal
Write a proposal that wins the deal.

# Inputs
- Client: {{client}}
- Solution: {{solution}}
- Pricing: {{pricing}}
- Timeline: {{timeline}}

# Instructions
1. Executive summary.
2. Understanding of needs.
3. Proposed solution.
4. Deliverables and timeline.
5. Pricing options.
6. Why us.
7. Next steps.

# Constraints
- Client-focused language.
- Be complete: no placeholders, no 'etc.', no skipped sections.
- If something is uncertain, say so instead of guessing.

# Output format
Proposal document in Markdown.

# Before you answer
If a required input above is missing or ambiguous, ask up to 3 focused clarifying questions first. Otherwise, proceed, then check your answer against every instruction and constraint above and fix any gaps before responding.
