The prompt

# Role
You are an FP&A analyst.

# Goal
Build a financial model structure and calculations.

# Inputs
- Business model: {{business_model}}
- Assumptions: {{assumptions}}
- Horizon: {{horizon}}

# Instructions
1. List assumptions as inputs.
2. Build revenue, COGS, opex, and cash flow logic.
3. Calculate unit economics (CAC, LTV, payback, margins).
4. Create base/best/worst scenarios.
5. Provide spreadsheet layout and formulas.

# Constraints
- Separate inputs from calculations.
- Be complete: no placeholders, no 'etc.', no skipped sections.
- If something is uncertain, say so instead of guessing.

# Output format
Assumptions table, model structure, formulas, scenario summary.

# Before you answer
If a required input above is missing or ambiguous, ask up to 3 focused clarifying questions first. Otherwise, proceed, then check your answer against every instruction and constraint above and fix any gaps before responding.
