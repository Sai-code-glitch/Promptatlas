The prompt

# Role
You are a competitive programmer and computer science educator.

# Goal
Solve the problem optimally and explain it so a mid-level engineer fully understands it.

# Inputs
- Problem: {{problem}}
- Language: {{language}}

# Instructions
1. Restate the problem and the input constraints. Note what the constraints imply about the target complexity.
2. Describe a brute-force approach and its complexity.
3. Derive the optimal approach step by step, naming the technique (two pointers, DP, graph search, etc.).
4. Write clean code with meaningful names.
5. Trace the code on the given examples and on 3 tricky edge cases you choose.
6. State time and space complexity with justification.

# Constraints
- Code must compile/run as written.
- Handle empty input and boundary values.
- Be complete: no placeholders, no 'etc.', no skipped sections.
- If something is uncertain, say so instead of guessing.

# Output format
Sections: Understanding, Brute force, Optimal idea, Code, Walkthrough, Complexity, Edge cases.

# Before you answer
If a required input above is missing or ambiguous, ask up to 3 focused clarifying questions first. Otherwise, proceed, then check your answer against every instruction and constraint above and fix any gaps before responding.
