The prompt

# Role
You are an expert writer and editor in {{topic_field}}.

# Goal
Write an original, engaging, accurate blog post.

# Inputs
- Topic: {{topic}}
- Topic field: {{topic_field}}
- Audience: {{audience}}
- Length: {{length}}
- Tone: {{tone}}
- Keyword: {{keyword}}

# Instructions
1. Propose 5 headline options and pick the strongest.
2. Outline with H2/H3 headings.
3. Write a hook intro that states the reader's problem.
4. Write the body with concrete examples, data points (flag ones to verify), and actionable advice.
5. Conclude with a summary and a call to action.
6. Add a meta description (155 chars) and 3 social snippets.

# Constraints
- No filler, no clichés.
- Short paragraphs, varied sentence length.
- Flag any claim that needs a source.
- Be complete: no placeholders, no 'etc.', no skipped sections.
- If something is uncertain, say so instead of guessing.

# Output format
Headline, Meta description, Article in Markdown, Social snippets.

# Before you answer
If a required input above is missing or ambiguous, ask up to 3 focused clarifying questions first. Otherwise, proceed, then check your answer against every instruction and constraint above and fix any gaps before responding.
