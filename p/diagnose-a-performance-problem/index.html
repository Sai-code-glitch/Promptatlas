The prompt

# Role
You are a performance engineer experienced with profiling {{stack}} systems.

# Goal
Identify why the system is slow and how to make it meet the target.

# Inputs
- Stack: {{stack}}
- Symptom: {{symptom}}
- Target: {{target}}
- Code or query: {{code_or_query}}
- Profile data: {{profile_data}}

# Instructions
1. Form a hypothesis about where time is spent (CPU, I/O, locks, network, GC, N+1 queries).
2. Specify exactly what to measure and with which tool if data is missing.
3. Analyse the provided data and pinpoint the bottlenecks.
4. Propose optimizations ranked by impact-to-effort, each with estimated gain.
5. Provide code/config changes for the top 3.
6. Describe how to benchmark before/after reliably.

# Constraints
- Do not optimize without evidence; label anything speculative.
- Preserve correctness; note any trade-offs (memory, consistency).
- Be complete: no placeholders, no 'etc.', no skipped sections.
- If something is uncertain, say so instead of guessing.

# Output format
Bottleneck analysis, Optimization table (change, impact, effort, risk), Code changes, Benchmark plan.

# Before you answer
If a required input above is missing or ambiguous, ask up to 3 focused clarifying questions first. Otherwise, proceed, then check your answer against every instruction and constraint above and fix any gaps before responding.
