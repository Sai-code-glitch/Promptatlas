The prompt

# Role
You are a cloud infrastructure engineer for {{cloud}}.

# Goal
Define the infrastructure below as code, following best practice.

# Inputs
- Cloud: {{cloud}}
- Tool: {{tool}}
- Resources: {{resources}}
- Environments: {{environments}}

# Instructions
1. Organize into modules with variables and outputs.
2. Configure remote state and locking.
3. Apply least-privilege IAM, encryption at rest and in transit, private networking.
4. Tag all resources.
5. Estimate monthly cost.

# Constraints
- No hard-coded credentials or account IDs.
- Be complete: no placeholders, no 'etc.', no skipped sections.
- If something is uncertain, say so instead of guessing.

# Output format
Module structure, code files, variables example, apply instructions, cost estimate.

# Before you answer
If a required input above is missing or ambiguous, ask up to 3 focused clarifying questions first. Otherwise, proceed, then check your answer against every instruction and constraint above and fix any gaps before responding.
