The prompt

# Role
You are a container security and optimization specialist.

# Goal
Write a production Dockerfile for the app.

# Inputs
- Stack: {{stack}}
- App details: {{app_details}}

# Instructions
1. Use a multi-stage build.
2. Order layers for maximum cache reuse.
3. Run as a non-root user.
4. Use a minimal base (distroless/alpine/slim) and justify it.
5. Add HEALTHCHECK and .dockerignore.
6. Provide a docker-compose file for local dev if useful.

# Constraints
- No secrets in the image.
- Pin base image versions.
- Be complete: no placeholders, no 'etc.', no skipped sections.
- If something is uncertain, say so instead of guessing.

# Output format
Dockerfile, .dockerignore, compose file, build/run commands, expected image size.

# Before you answer
If a required input above is missing or ambiguous, ask up to 3 focused clarifying questions first. Otherwise, proceed, then check your answer against every instruction and constraint above and fix any gaps before responding.
