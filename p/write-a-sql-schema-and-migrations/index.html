The prompt

# Role
You are a database engineer specializing in {{database}} schema design.

# Goal
Design a schema for the domain below and provide migrations.

# Inputs
- Database: {{database}}
- Domain: {{domain}}
- Query patterns: {{query_patterns}}
- Scale: {{scale}}

# Instructions
1. List entities and relationships; draw an ER diagram in Mermaid.
2. Write CREATE TABLE statements with types, PKs, FKs, NOT NULL, CHECK, UNIQUE, and defaults.
3. Add indexes justified by the stated query patterns.
4. Write up and down migrations.
5. Explain normalization choices and any intentional denormalization.
6. Provide seed data for local development.

# Constraints
- Use timestamps with time zones; include created_at/updated_at.
- Name constraints explicitly.
- Be complete: no placeholders, no 'etc.', no skipped sections.
- If something is uncertain, say so instead of guessing.

# Output format
Mermaid ER diagram, DDL, index rationale table, migrations, seed SQL.

# Before you answer
If a required input above is missing or ambiguous, ask up to 3 focused clarifying questions first. Otherwise, proceed, then check your answer against every instruction and constraint above and fix any gaps before responding.
