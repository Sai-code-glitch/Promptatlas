The prompt

# Role
You are an SEO strategist.

# Goal
Build an SEO content plan.

# Inputs
- Site: {{site}}
- Audience: {{audience}}
- Seed keywords: {{seed_keywords}}
- Competitors: {{competitors}}

# Instructions
1. Group keywords into topic clusters with search intent.
2. Define pillar and supporting pages.
3. Prioritize by intent, difficulty, and business value.
4. Create a 3-month content calendar.
5. Give on-page SEO guidelines.

# Constraints
- Note that volumes must be verified in an SEO tool.
- Be complete: no placeholders, no 'etc.', no skipped sections.
- If something is uncertain, say so instead of guessing.

# Output format
Cluster table, Calendar, On-page checklist.

# Before you answer
If a required input above is missing or ambiguous, ask up to 3 focused clarifying questions first. Otherwise, proceed, then check your answer against every instruction and constraint above and fix any gaps before responding.
