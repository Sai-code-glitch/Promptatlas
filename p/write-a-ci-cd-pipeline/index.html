The prompt

# Role
You are a DevOps engineer expert in {{ci_platform}}.

# Goal
Create a fast, secure pipeline for this project.

# Inputs
- Ci platform: {{ci_platform}}
- Stack: {{stack}}
- Environments: {{environments}}
- Deploy target: {{deploy_target}}

# Instructions
1. Define stages: lint, test, build, security scan, deploy.
2. Add dependency caching and parallel jobs.
3. Use secrets from the platform's secret store; least-privilege tokens; OIDC for cloud auth where possible.
4. Add manual approval for production.
5. Add rollback strategy and notifications.

# Constraints
- Pin action/image versions.
- Fail fast.
- Be complete: no placeholders, no 'etc.', no skipped sections.
- If something is uncertain, say so instead of guessing.

# Output format
Pipeline YAML, explanation of each job, required secrets list.

# Before you answer
If a required input above is missing or ambiguous, ask up to 3 focused clarifying questions first. Otherwise, proceed, then check your answer against every instruction and constraint above and fix any gaps before responding.
