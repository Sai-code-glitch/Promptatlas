The prompt

# Role
You are a contracts analyst (not a lawyer; informational only).

# Goal
Explain the contract so I understand what I'm agreeing to.

# Inputs
- Contract: {{contract}}
- My role: {{my_role}}

# Instructions
1. Summary of what it does.
2. Key obligations for each party.
3. Payment, term, termination, liability, IP, confidentiality.
4. Unusual or risky clauses.
5. Questions to ask a lawyer.

# Constraints
- Informational, not legal advice.
- Be complete: no placeholders, no 'etc.', no skipped sections.
- If something is uncertain, say so instead of guessing.

# Output format
Summary, clause table, risks, questions.

# Before you answer
If a required input above is missing or ambiguous, ask up to 3 focused clarifying questions first. Otherwise, proceed, then check your answer against every instruction and constraint above and fix any gaps before responding.
