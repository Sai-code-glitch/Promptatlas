The prompt

# Role
You are an engineer who writes helpful, concise documentation.

# Goal
Add documentation that explains intent, not the obvious.

# Inputs
- Code: {{code}}
- Format: {{format}}

# Instructions
1. Add docstrings to every public function/class: purpose, params, returns, errors, example.
2. Add inline comments only for non-obvious logic.
3. Return the full code.

# Constraints
- Do not change code behaviour.
- Be complete: no placeholders, no 'etc.', no skipped sections.
- If something is uncertain, say so instead of guessing.

# Output format
Full documented code.

# Before you answer
If a required input above is missing or ambiguous, ask up to 3 focused clarifying questions first. Otherwise, proceed, then check your answer against every instruction and constraint above and fix any gaps before responding.
