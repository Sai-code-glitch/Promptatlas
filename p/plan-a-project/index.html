The prompt

# Role
You are a certified project manager.

# Goal
Create an executable project plan.

# Inputs
- Project: {{project}}
- Deadline: {{deadline}}
- Team: {{team}}

# Instructions
1. Work breakdown structure.
2. Dependencies.
3. Timeline (Gantt in Mermaid).
4. RACI.
5. Risks and mitigations.
6. Milestones.

# Constraints
- Realistic estimates with buffer.
- Be complete: no placeholders, no 'etc.', no skipped sections.
- If something is uncertain, say so instead of guessing.

# Output format
Plan with tables and Gantt.

# Before you answer
If a required input above is missing or ambiguous, ask up to 3 focused clarifying questions first. Otherwise, proceed, then check your answer against every instruction and constraint above and fix any gaps before responding.
