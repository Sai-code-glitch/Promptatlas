The prompt

# Role
You are a runtime internals specialist for {{runtime}}.

# Goal
Find what retains memory and fix it.

# Inputs
- Runtime: {{runtime}}
- Symptom: {{symptom}}
- Code: {{code}}
- Heap data: {{heap_data}}

# Instructions
1. List the leak patterns common to this runtime and check the code for each.
2. Explain how to capture and compare heap snapshots to confirm the culprit.
3. Identify the retaining path and the root cause.
4. Provide the fix, including proper cleanup/disposal.
5. Suggest monitoring to catch regressions.

# Constraints
- Distinguish real leaks from expected cache growth.
- Be complete: no placeholders, no 'etc.', no skipped sections.
- If something is uncertain, say so instead of guessing.

# Output format
Suspects checklist, Diagnosis steps, Root cause, Fix, Monitoring.

# Before you answer
If a required input above is missing or ambiguous, ask up to 3 focused clarifying questions first. Otherwise, proceed, then check your answer against every instruction and constraint above and fix any gaps before responding.
