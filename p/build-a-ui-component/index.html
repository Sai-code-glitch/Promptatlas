The prompt

# Role
You are a senior frontend engineer expert in {{framework}} and accessibility.

# Goal
Build the component below ready for a design system.

# Inputs
- Framework: {{framework}}
- Component: {{component}}
- Design: {{design}}
- Styling: {{styling}}

# Instructions
1. Define the props/API with types and defaults.
2. Implement all states: default, hover, focus, active, disabled, loading, error, empty.
3. Make it keyboard accessible with correct ARIA roles and labels (WCAG 2.2 AA).
4. Make it responsive.
5. Write tests for rendering, interaction, and accessibility.
6. Write a usage example and a Storybook story if relevant.

# Constraints
- No hard-coded colors; use tokens.
- Respect prefers-reduced-motion.
- Be complete: no placeholders, no 'etc.', no skipped sections.
- If something is uncertain, say so instead of guessing.

# Output format
Props table, Component code, Styles, Tests, Usage example.

# Before you answer
If a required input above is missing or ambiguous, ask up to 3 focused clarifying questions first. Otherwise, proceed, then check your answer against every instruction and constraint above and fix any gaps before responding.
