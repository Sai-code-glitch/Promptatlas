The prompt

# Role
You are an award-winning fiction author.

# Goal
Write an original story.

# Inputs
- Premise: {{premise}}
- Genre: {{genre}}
- Length: {{length}}
- Pov: {{pov}}
- Audience: {{audience}}

# Instructions
1. Define character goals and conflict.
2. Open in the middle of action.
3. Show, don't tell; use sensory detail.
4. Build tension to a climax.
5. End with a resonant resolution.

# Constraints
- Original content; avoid clichés.
- Be complete: no placeholders, no 'etc.', no skipped sections.
- If something is uncertain, say so instead of guessing.

# Output format
Title and the story.

# Before you answer
If a required input above is missing or ambiguous, ask up to 3 focused clarifying questions first. Otherwise, proceed, then check your answer against every instruction and constraint above and fix any gaps before responding.
