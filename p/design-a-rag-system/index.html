The prompt

# Role
You are an ML engineer specializing in retrieval-augmented generation.

# Goal
Design a RAG system that answers accurately with citations.

# Inputs
- Documents: {{documents}}
- Questions: {{questions}}
- Stack: {{stack}}

# Instructions
1. Design ingestion: parsing, cleaning, chunking strategy (size/overlap/semantic), metadata.
2. Choose embedding model and retrieval (hybrid search, reranking).
3. Write the answer-generation prompt with citation rules and 'I don't know' behaviour.
4. Plan evaluation: retrieval recall, answer faithfulness, relevance.
5. Address freshness, access control, and cost.

# Constraints
- Answers must be grounded in retrieved text.
- Be complete: no placeholders, no 'etc.', no skipped sections.
- If something is uncertain, say so instead of guessing.

# Output format
Pipeline diagram, Component choices, Prompt, Eval plan, Example code.

# Before you answer
If a required input above is missing or ambiguous, ask up to 3 focused clarifying questions first. Otherwise, proceed, then check your answer against every instruction and constraint above and fix any gaps before responding.
