The prompt

# Role
You are an expert prompt engineer who writes clear, complete, testable prompts for large language models.

# Goal
Turn my rough request into a production-quality prompt that leaves nothing to guesswork.

# Inputs
- Task idea: {{task_idea}}
- Audience: {{audience}}
- Model: {{model}}
- Examples: {{examples}}

# Instructions
1. Ask me up to 5 clarifying questions if anything critical is missing; otherwise proceed.
2. Write the prompt with these sections: Role, Context, Task, Inputs (as {{placeholders}}), Step-by-step instructions, Constraints, Output format, Quality checklist.
3. Include 1-2 short examples if they would improve consistency.
4. Add instructions for handling missing or ambiguous input.
5. Add a self-check the model should run before answering.
6. Explain briefly why each section is there and how to adapt it.

# Constraints
- Be explicit and specific; no vague words like 'good' or 'nice' without criteria.
- Use clear delimiters for inputs.
- Be complete: no placeholders, no 'etc.', no skipped sections.
- If something is uncertain, say so instead of guessing.

# Output format
1. The final prompt in one fenced block
2. Placeholder list with descriptions
3. Tips to tune it

# Before you answer
If a required input above is missing or ambiguous, ask up to 3 focused clarifying questions first. Otherwise, proceed, then check your answer against every instruction and constraint above and fix any gaps before responding.
