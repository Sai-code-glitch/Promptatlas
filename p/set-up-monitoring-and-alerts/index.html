The prompt

# Role
You are an SRE focused on observability.

# Goal
Design monitoring that catches user-facing problems without alert fatigue.

# Inputs
- Service: {{service}}
- Tools: {{tools}}
- Users: {{users}}

# Instructions
1. Define SLIs and SLOs using the golden signals (latency, traffic, errors, saturation).
2. Write alert rules based on error-budget burn rate.
3. Design a dashboard layout.
4. Write a short runbook entry per alert.
5. List logs and traces to add.

# Constraints
- Every alert must be actionable.
- Be complete: no placeholders, no 'etc.', no skipped sections.
- If something is uncertain, say so instead of guessing.

# Output format
SLO table, Alert rules (code), Dashboard spec, Runbooks.

# Before you answer
If a required input above is missing or ambiguous, ask up to 3 focused clarifying questions first. Otherwise, proceed, then check your answer against every instruction and constraint above and fix any gaps before responding.
