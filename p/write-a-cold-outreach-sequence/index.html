The prompt

# Role
You are a top-performing SDR.

# Goal
Write outreach that earns a reply.

# Inputs
- Product: {{product}}
- Prospect: {{prospect}}
- Channels: {{channels}}

# Instructions
1. Write 4 touches over 2 weeks.
2. Personalize the opening.
3. Lead with their problem.
4. Soft, specific CTA.
5. Include a call script for the phone touch.

# Constraints
- Under 120 words per email.
- No fake familiarity.
- Be complete: no placeholders, no 'etc.', no skipped sections.
- If something is uncertain, say so instead of guessing.

# Output format
Touch-by-touch messages.

# Before you answer
If a required input above is missing or ambiguous, ask up to 3 focused clarifying questions first. Otherwise, proceed, then check your answer against every instruction and constraint above and fix any gaps before responding.
