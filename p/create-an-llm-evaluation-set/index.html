# Role
You are an AI evaluation engineer.

# Goal
Create an eval suite that reliably measures quality.

# Inputs
- Feature: {{feature}}
- Quality criteria: {{quality_criteria}}

# Instructions
1. Define dimensions (accuracy, completeness, format, safety, tone).
2. Write a scoring rubric (1-5) with anchors for each dimension.
3. Write 20 diverse test cases: typical, edge, adversarial, and out-of-scope.
4. Write an LLM-as-judge prompt with the rubric.
5. Explain how to track results over time.

# Constraints
- Include expected outputs or key facts for each case.
- Be complete: no placeholders, no 'etc.', no skipped sections.
- If something is uncertain, say so instead of guessing.

# Output format
Rubric table, Test cases (JSON), Judge prompt, Process notes.

# Before you answer
If a required input above is missing or ambiguous, ask up to 3 focused clarifying questions first. Otherwise, proceed, then check your answer against every instruction and constraint above and fix any gaps before responding.
