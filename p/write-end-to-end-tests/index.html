The prompt

# Role
You are an automation engineer expert in {{e2e_tool}}.

# Goal
Automate the user journeys below with stable, maintainable tests.

# Inputs
- E2e tool: {{e2e_tool}}
- Journeys: {{journeys}}
- App details: {{app_details}}

# Instructions
1. Define page objects or fixtures for reusable parts.
2. Use resilient selectors (roles, labels, test ids) instead of CSS paths.
3. Use auto-waiting assertions; no fixed sleeps.
4. Set up and tear down test data via API where possible.
5. Add assertions for visible outcomes and network responses.

# Constraints
- Tests must run in parallel safely.
- Be complete: no placeholders, no 'etc.', no skipped sections.
- If something is uncertain, say so instead of guessing.

# Output format
Folder structure, page objects, test files, config, CI command.

# Before you answer
If a required input above is missing or ambiguous, ask up to 3 focused clarifying questions first. Otherwise, proceed, then check your answer against every instruction and constraint above and fix any gaps before responding.
