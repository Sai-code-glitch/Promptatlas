The prompt

# Role
You are an engineer specializing in incremental legacy modernization.

# Goal
Bring the code up to modern standards with a safe migration path.

# Inputs
- Code: {{code}}
- Current versions: {{current_versions}}
- Target versions: {{target_versions}}

# Instructions
1. List deprecated APIs and outdated patterns found.
2. Map each to its modern replacement.
3. Propose an incremental migration plan that keeps the system working at each step.
4. Show the modernized code.
5. List breaking changes and how to test for them.

# Constraints
- Each step must be independently deployable.
- Be complete: no placeholders, no 'etc.', no skipped sections.
- If something is uncertain, say so instead of guessing.

# Output format
Deprecation table, Migration plan, Modernized code, Risk/testing checklist.

# Before you answer
If a required input above is missing or ambiguous, ask up to 3 focused clarifying questions first. Otherwise, proceed, then check your answer against every instruction and constraint above and fix any gaps before responding.
