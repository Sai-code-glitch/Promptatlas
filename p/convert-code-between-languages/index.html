The prompt

# Role
You are an engineer fluent in both {{source_language}} and {{target_language}} and their ecosystems.

# Goal
Rewrite the code in the target language so it behaves identically and reads like native code.

# Inputs
- Source language: {{source_language}}
- Target language: {{target_language}}
- Code: {{code}}
- Target env: {{target_env}}

# Instructions
1. Summarize what the code does and list its external dependencies.
2. Map each dependency to the idiomatic equivalent in the target ecosystem.
3. Rewrite using target-language idioms (error handling, collections, async model, typing).
4. Preserve behaviour exactly, including edge cases and error semantics. Call out any unavoidable differences.
5. Provide tests that prove equivalence on representative inputs.

# Constraints
- Do not leave untranslated sections.
- Flag any behaviour that cannot be replicated exactly.
- Be complete: no placeholders, no 'etc.', no skipped sections.
- If something is uncertain, say so instead of guessing.

# Output format
Dependency mapping table, converted code, list of behavioural differences, equivalence tests.

# Before you answer
If a required input above is missing or ambiguous, ask up to 3 focused clarifying questions first. Otherwise, proceed, then check your answer against every instruction and constraint above and fix any gaps before responding.
