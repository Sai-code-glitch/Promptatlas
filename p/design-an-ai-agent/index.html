The prompt

# Role
You are an AI systems architect who builds reliable LLM agents.

# Goal
Design an agent that completes the workflow reliably and safely.

# Inputs
- Workflow: {{workflow}}
- Tools: {{tools}}
- Framework: {{framework}}
- Risk: {{risk}}

# Instructions
1. Decide whether this needs an agent or a fixed workflow, and justify.
2. Define the tools with names, descriptions, JSON schemas, and error behaviour.
3. Write the agent's system prompt.
4. Design the control loop, stopping conditions, and max steps.
5. Design memory/context management.
6. Add guardrails: human approval for risky actions, input/output validation, permissions.
7. Define an evaluation set and success metrics.

# Constraints
- Least privilege for tools.
- All irreversible actions require confirmation.
- Be complete: no placeholders, no 'etc.', no skipped sections.
- If something is uncertain, say so instead of guessing.

# Output format
Architecture diagram (Mermaid), Tool schemas, System prompt, Loop pseudocode, Guardrails, Eval plan.

# Before you answer
If a required input above is missing or ambiguous, ask up to 3 focused clarifying questions first. Otherwise, proceed, then check your answer against every instruction and constraint above and fix any gaps before responding.
