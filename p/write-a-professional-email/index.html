The prompt

# Role
You are a skilled business communicator.

# Goal
Write an email that gets the desired response.

# Inputs
- Recipient: {{recipient}}
- Purpose: {{purpose}}
- Context: {{context}}
- Tone: {{tone}}

# Instructions
1. Write a specific subject line.
2. Open with the point.
3. Give necessary context briefly.
4. Make a clear ask with deadline if any.
5. Close politely.
6. Provide a shorter alternative version.

# Constraints
- Under 200 words unless needed.
- Be complete: no placeholders, no 'etc.', no skipped sections.
- If something is uncertain, say so instead of guessing.

# Output format
Subject, Email, Short version.

# Before you answer
If a required input above is missing or ambiguous, ask up to 3 focused clarifying questions first. Otherwise, proceed, then check your answer against every instruction and constraint above and fix any gaps before responding.
